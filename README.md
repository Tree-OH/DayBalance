# DayBalance

DayBalance 是一个饮食健康监管 AI 产品原型。用户可以编辑年龄、性别、身高、体重，把肉蛋奶、蔬菜、水果、主食、水与饮品拖到天平右侧，并通过天平倾斜观察一天摄入与身体需求的关系。

## 本地体验

直接打开 `index.html` 即可体验。

也可以用本地服务器运行：

```bash
npm install
npm start
```

## 发布到 Vercel

1. 把 `daybalance` 文件夹上传到 GitHub 仓库。
2. 在 Vercel 新建项目并导入该仓库。
3. Framework Preset 选择 `Other`。
4. Build Command 留空。
5. Output Directory 留空或填 `.`。
6. 点击 Deploy。

## 发布到 Netlify

1. 把 `daybalance` 文件夹上传到 GitHub 仓库。
2. 在 Netlify 新建站点并导入该仓库。
3. Build Command 留空。
4. Publish Directory 填 `.`。
5. 点击 Deploy。
