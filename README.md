# DayBalance
 一个基于 AI 的交互式饮食健康平衡模拟系统，通过“天平”可视化地帮助用户理解每日饮食摄入与身体状态之间的关系。  ## 项目简介  DayBalance 是一个以“饮食平衡”为核心概念的 AI 健康管理产品原型。  整个产品围绕一个动态天平展开：  - 天平左侧代表用户自身身体状态 - 天平右侧代表一天的饮食摄入  用户可以自由调整人物数据，包括：  - 年龄 - 性别 - 身高 - 体重  同时，用户可以将下方不同类别的食物卡片拖拽到天平右侧，并设置对应摄入重量，用来模拟一天的饮食情况。  系统会根据用户身体数据与饮食摄入情况进行实时分析，并通过天平倾斜动态反馈身体与饮食之间的“平衡关系”。
